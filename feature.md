## Goal and Boundaries

Respect the active Qt/operating-system palette and application font in the main window, candidate rows, and child dialogs. Support light, dark, high-contrast, and enlarged-text settings without reducing keyboard focus visibility. Keep the existing scan, review, quarantine, update, and privacy contracts. Do not add a theme selector, save theme preferences, change the application-menu label, or redesign the window; those are separate UI backlog items.

Original problem: `MainWindow._apply_style()` in `src/img_ai_filter/window.py` assigned `background`, `color`, and pixel font sizes to `QMainWindow, QWidget` and named children. This overrode system themes. Candidate rows use item widgets with a bounded 96-pixel preview. `MainWindow` sets a 560 by 400 minimum; the content scroll area disables horizontal scroll. `tests/test_window.py::test_review_controls_have_visible_keyboard_focus_styles` checks that the result list and secondary buttons have focus selectors.

## Exact Implementation Tasks (only after intended test failures)

1. In `src/img_ai_filter/window.py`, remove `QMainWindow, QWidget` background/color/pixel-font overrides and every fixed-hex foreground/background/selection rule that prevents palette inheritance. Let QPalette supply normal, disabled, highlighted, and text-input colors. Preserve visual hierarchy with weight, spacing, and scalable font-relative size where needed, never fixed pixel font sizes. 3. Recalculate row height from the actual font metrics and wrapped text at the available width after initial render, resize, and font change. Keep bounded previews in memory and at most 96 by 96. Retain item data, check state, selection behavior, and the scrollable main content.
4. Review existing minimum-size assignments and label layouts only where scaling tests prove clipping; allow vertical scrolling at 560 by 400 and retain a visible header menu. Do not take on the separate narrow-width horizontal-layout redesign.
5. Update any documentation that describes fixed visual colors to describe system palette/font support. Avoid unrelated changes to setup, transport, scan, history storage, or quarantine.
